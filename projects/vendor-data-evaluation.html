Third-Party Data Vendor Evaluation

Built a LightGBM + SHAP pipeline to answer a real renewal question: does this vendor's data actually predict anything, or are we paying for noise?

Python LightGBM SHAP Data Science

01 Problem

Before renewing a pricey third-party data subscription, leadership needed a real answer: does this vendor's IP-enrichment data actually predict streaming conversion, or are we paying for noise dressed up as signal?

02 Technical Highlights

I built a pipeline that joins the vendor's IP-level data to our streaming campaign data, trims outliers, and runs it through two tests: a straightforward statistical screen and a LightGBM model with SHAP to see whether the vendor's features add real predictive lift over a campaign-only baseline. The real test is out-of-fold AUC grouped by campaign, so the model can't just memorize which campaign it's looking at and call that a win. I also scoped the data lookup down to only the IPs that actually mattered, which cut what it cost to run the analysis by a large margin.

03 Outcome

I ran the full pipeline end to end and delivered the results and a recommendation to leadership as part of the renewal review, giving them a clean yes-or-no answer instead of a vague "seems fine." I moved on before the final renewal call was made, so I don't know which way it landed, but the analysis gave leadership a real answer to decide from instead of a guess.
