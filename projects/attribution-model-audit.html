TV Attribution Model Audit & Rebuild

Rebuilt and stress-tested a minute-level TV attribution model that credits web traffic spikes to TV airings — to find out where that method is actually valid, where it isn't, and what should replace it.

Statistics Machine Learning Python Causal Inference

01 Problem

An existing minute-level TV attribution model credited website traffic spikes to TV airings and reported those results with high confidence — but the method has a known weakness: normal traffic noise can look exactly like a real response if you're not careful. No one had rigorously tested how much of the model's claimed impact was real signal versus noise that happened to line up with an airing.

02 Approach

  • Re-implemented the existing legacy model from scratch in a modern data platform, verifying it matched the original bit-for-bit before changing anything — so any later differences could be attributed to methodology, not a reimplementation bug.
  • Built a signal-detection harness that tests each client for a real, statistically detectable TV-to-web response using regression combined with placebo tests run against fake, shuffled airing schedules — if a "response" shows up even against a schedule that never aired, it's not real signal.
  • Built a per-client routing table that assigns each campaign to the measurement method appropriate to its signal strength — minute-level attribution, a lagged/panel-based method, or "insufficient data yet" — rather than applying one method universally.
  • Built a second-generation model with a learned traffic baseline and an explicit "honesty gate" that zeroes out any claimed impact that can't beat its own placebo test, then ran a pre-registered head-to-head comparison against the original model.

03 Technical Highlights

  • Placebo/fake-schedule testing as a validity check — the core methodological move: if a model shows a "response" to an airing that never happened, that tells you how much of its real-schedule result is noise, not signal.
  • Per-client signal routing — rather than assuming one method fits every campaign, each client is tested individually and routed to whichever measurement approach its own data can actually support.
  • An explicit honesty gate — the rebuilt model is structurally prevented from reporting an effect it can't distinguish from its own placebo baseline, rather than relying on a human to catch overconfident output after the fact.
  • Pre-registered model face-off — old vs. new model comparison criteria were fixed before results were seen, to keep the evaluation honest.

04 Outcome

The audit found that, for most tested clients, a large majority of the legacy model's claimed impact was statistical artifact rather than a real response — and quantified that minute-level attribution is only defensible for a modest share of total spend, with the remainder better served by a lagged/panel-based method. The rebuilt model outperformed the legacy one on every validation metric. Findings were packaged into a leadership-facing deliverable and are currently under review as the basis for a company-wide attribution methodology change.
