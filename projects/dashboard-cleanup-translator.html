Dashboard Cleanup & Legacy Pipeline Translator

Two backend tools: one that automatically flags stale BI assets for cleanup, and one that turns old dataflow logic into ready-to-run code.

Python Databricks LLM Integration Automation

01 Problem

Dashboards and dataflows piled up faster than anyone could keep track of, and nobody had a good way to know what was actually still in use. Separately, translating old dataflow logic into new pipeline code by hand was slow and repetitive.

02 Technical Highlights

I built a monthly cleanup tool that pulls in all of a BI platform's metadata, compares snapshots over time to catch what's been deleted and by whom, and flags stale or oversized assets nobody's touched. Each owner gets a monthly email listing exactly what's flagged for them, plus a weekly summary tracking how much actually gets cleaned up. On the translation side, I built a tool that takes an old dataflow, sends its logic to an LLM using a couple of markdown files as the instructions, and outputs a ready-to-run notebook in the new format, with a syntax check built in so bad output gets flagged instead of silently saved.

03 Outcome

The cleanup tool runs on its own schedule today and has been steadily nudging owners to clear out unused assets for months. The translation tool works end to end and turns what used to be a manual rebuild into pasting in an ID and hitting run, with every translation logged for review.
