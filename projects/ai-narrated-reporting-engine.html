AI-Narrated, Fact-Audited Reporting Engine

One reporting engine that writes client-ready narratives, but only lets the AI cite facts we already verified.

LLM Integration Python Databricks Report Automation

01 Problem

Client reporting was spread across several separate report builders, each with its own formatting and manually written narrative, which was slow to produce and easy to get subtly wrong.

02 Technical Highlights

I helped build one pipeline that generates every report type from a shared codebase instead of four separate ones. Every report starts as a "fact packet" computed straight from the data, no AI involved, and only then does an LLM write the narrative on top, restricted to citing facts that are actually in that packet. Every generated claim gets automatically re-checked against the packet afterward as a hallucination check, and everything gets combined into one interactive report with charts, competitive context, and milestones for a client's full campaign lineup.

03 Outcome

All the report types have been migrated over from their old builders and checked against prior outputs, including combined multi-campaign reports. It's now live and generating reports on a regular schedule, and a next-generation viewer for these reports has already been packaged and handed off for deployment.
