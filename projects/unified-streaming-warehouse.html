Unified Streaming Data Warehouse

Turned dozens of separate, inconsistent client tables into one standardized table that everything else reads from.

Databricks PySpark Delta Lake Data Engineering

01 Problem

Every client's streaming data lived in its own table with its own quirks, so any report that needed more than one client meant writing custom code just for that report. There was no single place to go for a cross-client answer.

02 Technical Highlights

I built a job that automatically finds each client's model table and folds it into one shared schema, using a few flexible metric slots since not every client tracks the same things the same way. New clients only get pulled in once they have enough history to be reliable, and the whole thing refreshes twice a day in Databricks. While tracing through the write logic I also caught a setting that looked like a safe way to speed things up, but would have actually wiped out historical data if I'd flipped it, so I left it off and flagged it for a proper fix later.

03 Outcome

Reports that used to mean stitching together data from dozens of clients now just query one table. New clients get folded in automatically instead of needing a manual setup step every time someone onboards. And catching that data-wiping bug before it ever ran in production saved a real headache down the line.
